# うさぎのたいやき - iPhone Widget App

うさぎのキャラクター「たいやき」のお世話ができるインタラクティブなウィジェットアプリです。

## 実装済みの機能 (Update)
1.  **キャラクター設定**
    - 名前: たいやき
    - 種類: うさぎ
2.  **メインアプリ UI (`ContentView.swift`)**
    - 日本語 UI に変更。
    - 絵文字から画像表示に変更。
3.  **インタラクティブ・ウィジェット (`PetWidget.swift`)**
    - 日本語化および画像対応。

## 最新の画像アセット (Gauge & Speech Bubble) の活用
新しく追加された画像アセットを UI に統合しました：
- `Hunger_level_gauge`: おなかのゲージ
- `Mood_level_gauge`: しあわせのゲージ
- `Fluffiness_Level_Gauge`: ふわふわ度のゲージ
- `speech_bubble`: 吹き出し画像

### ペットの仕様変更
どうぶつを 1 種類に絞り、シンプルな構成に変更しました。

**必要な画像アセット (Assets.xcassets):**
- `pet_character_born`: 生まれたてのペット
- `pet_character_fine`: 大人のペット（後ほど作成予定）

### そうじ機能
ペットが大人 (`fine`) になると、時間経過で「うんち」をすることがあります。
- うんちがある場合、画面に `poop_1`, `poop_2`, `poop_3` の画像が表示されます。
- 「そうじ」ボタンを押すと掃除ができ、ペットのしあわせ度がアップします。
- ウィジェット上でも、うんちがある時は自動的に「そうじ」ボタンが表示されます。

## しゃべる機能 (Speech System)
うさぎの「たいやき」が状況に応じてしゃべるようになりました。
- **ステータス連動**: おなかが空くと「おりぇ〜 えさよこせ〜」、うんちがあると「そうじしてくれ〜」など、状態によってセリフが変わります。
- **アクション反応**: ごはんをあげると「うめぇ〜！」、あそぶと「たのしいぜ！」と反応します。
- **ランダム発言**: 特に問題がない時も、「おりぇ、たいやき！」「ふわふわだろ〜」などとランダムにしゃべります。

## Xcode でのセットアップ方法
Mac の Xcode で新規プロジェクトを作成し、作成したファイルを配置してください。

1.  **Xcode プロジェクトの作成:**
    - "iOS App" プロジェクトを新規作成 (名前: `TaiyakiPet`)。
    - インターフェースは "SwiftUI" を選択。
2.  **ウィジェットターゲットの追加:**
    - `File > New > Target...` から "Widget Extension" を追加 (名前: `TaiyakiPetWidget`)。
    - "Include Configuration Intent" のチェックは外してOK。
3.  **App Groups の設定 (重要!):**
    - アプリとウィジェット間でデータを共有するために、両方のターゲットの `Signing & Capabilities` タブで `App Groups` を追加します。
    - ID を `group.com.taiyaki.pet`（または自身で決めたもの）に設定し、`PetData.swift` 内の `appGroupIdentifier` もそれに合わせます。
4.  **ファイルの配置:**
    - 実装した `.swift` ファイルをそれぞれのターゲットに追加します。
    - `PetData.swift` はアプリとウィジェットの両方のターゲットに含める必要があります。
